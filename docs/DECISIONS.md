- D-001: контейнер = JSON + base64, UTF-8/LF (паритет платформ, отлаживаемость)
- D-002: KDF = Argon2id через BouncyCastle (чистая Java, без JNI)
- D-003: миграций нет; старые базы не читаем; перенос руками
- D-004: single Activity + Compose Navigation; гейт по состоянию сессии
- D-005: синк = общий файл в синхронизируемой папке + детерминированный merge по updatedAt
- D-006: JSON-либа ядра = kotlinx.serialization (строгая схема, KMP-совместимость на будущее)
- D-007: ядро = отдельный Gradle-модуль :core (pure Kotlin/JVM, пакет com.c0dex.core, ноль Android-импортов); Windows-порт подключает его как есть; тесты ядра на JVM.
- D-008: дефолты сессии приняты: grace 0, idle 5 мин, буфер 30 с, лок-скрин показывает только имя файла базы.
- D-009: главный экран после разблокировки — список записей; генератор — опция (из списка и из поля пароля при редактировании), не отдельный главный экран.
- D-010: генератор — доменная логика в :core (паритет Android/Windows); размещение в UI — по D-009 (опция, не главный экран).
- D-011: запись vault = прямая truncate-запись по стабильному Uri; атомарный rename через SAF отклонён (меняет document-id, ломает ссылку); recovery = версии облака.
