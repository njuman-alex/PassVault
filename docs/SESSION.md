# SESSION.md — сессия, лок-модель, политика секретов
Версия: 1.4 (amendment D-031).

## 1. Машина состояний
[LOCKED] --успешный unwrap DEK--> [UNLOCKED]
[UNLOCKED] --лок-триггер--> [LOCKED] (DEK стирается из памяти)

- LOCKED: DEK в памяти нет; UI = только лок-скрин
  (Разблокировать / Создать vault / Recovery-заглушка). Ни списка, ни названий.
- UNLOCKED: DEK только в памяти (holder уровня приложения); полный UI.
- Смерть процесса = автоматически LOCKED.

## 2. Лок-триггеры
1. Ручной лок (кнопка в тулбаре).
2. Уход в фон / потеря фокуса: grace=0 → лок НЕМЕДЛЕННО в ON_STOP / onFocusLost (D-023);
      grace>0 → лок при возвращении, если фон длился дольше grace. Узкие исключения — только
      наши файловые диалоги:
      • Android (SAF): один ON_STOP без лока, pickerFlow ставится в ON_STOP, возврат не лочит
      при elapsed ≤ 10 мин — решение не зависит от порядка onActivityResult/ON_START;
      HOME из пикера обходом не является.
      • Десктоп (JFileChooser): withFileDialog держит fileDialogOpen на время диалога плюс
      «тихий хвост» 750 мс после закрытия; в этом окне не лочат ни onFocusLost, ни
      onFocusGained (D-030) — AWT шлёт transient focusedWindow=null при открытии и закрытии.
      Alt-tab/уход в фон без диалога лочит по общему правилу.
3. Idle-таймер неактивности, дефолт 5 мин (0 = выкл). Пока открыт диалог (добавление,
      генератор, подтверждение удаления, смена мастера, файловый чузер) idle не лочит:
      счётчик вложенности dialogDepth в сессии, кап 10 мин (D-031). Ручной лок и фон/фокус — как прежде.
4. Ротация мастера — сессия пересоздаётся под новый KEK.

## 3. Стирание при локе
- DEK: fill(0), holder обнуляется.
- Кэш расшифрованных payload'ов — сброс.
- Поля ввода мастера/паролей в UI-состояниях — сброс.
- Буфер обмена — по политике п.5, не при локе.

## 4. Анти-брутфорс
- Счётчик неудач в обычных prefs (не секрет).
- Задержки: 1-4 провала — 0; 5+ — 5 с; 10+ — 30 с; 20+ — 5 мин. Сброс после успеха.
- Блокировок «навсегда» нет.

## 5. Буфер обмена
- Автоочистка через 30 с после копирования (настраиваемо, 0 = выкл).
- Android 13+: клип помечается sensitive.
- Копирование только в UNLOCKED.

## 6. Ошибки лок-скрина
- unwrap не сошёлся -> «Неверный мастер-пароль» (+ счётчик).
- файл не парсится -> «Файл повреждён или не PMV3».
- файла нет -> флоу создания vault (мастер + подтверждение -> DEK -> wrap -> контейнер).
- битые/абсурдные параметры KDF или OOM при derive -> «Файл повреждён или не PMV3» (D-025).

## 7. Навигационный гейт
- В LOCKED граф UI физически не содержит экранов vault.
- Back на лок-скрине = выход из приложения.
- Android: launcher-activity exported=true (системное требование); других activity нет; обходов через intents нет.

## 8. Дефолты (приняты)
- grace при фоне: 0 (сразу).
- idle: 5 мин.
- буфер: 30 с.
- лок-скрин показывает имя файла базы, но ни одной записи/названия.
